# Student Performance Predictor ML

## Project Overview

This project predicts a student's final exam score using Machine Learning.

The project includes:

- Data Analysis
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Linear Regression
- Model Evaluation
- Streamlit Web Application

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
